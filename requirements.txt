# NOTE on version pinning (a real DevOps lesson):
#   Exact pins like "pandas==2.2.2" guarantee everyone gets the SAME version —
#   great for reproducibility, BUT only when the Python version is also fixed
#   (our CI uses Python 3.11, so it works there). On a fresh machine with a
#   NEWER Python, an old exact pin may have no prebuilt "wheel", forcing pip to
#   compile from source (which needs a C++ compiler and usually fails on Windows).
#
#   So here we use MINIMUM versions ( >= ) instead. pip then downloads the
#   newest prebuilt wheel that matches whatever Python you have installed.
#   In a real production project you'd lock BOTH the package and Python versions
#   (via Docker or a lockfile) so they always match.
#
# Install with:  pip install -r requirements.txt
